## The dataset

A 1,500 bp reference gene with a 5' UTR (1–100), a 1,299 bp coding sequence (101–1,399; 433 codons → 432 aa) carrying a **glycine-rich loop** (codons 60–65) and a **catalytic DxxxxN motif** (codons 200–205), and a 3' UTR (1,400–1,500) with an AATAAA polyadenylation signal. Twelve samples were derived by applying a documented catalogue of edits; the simulation script **asserts every designed effect** after construction (no internal stop in the reference, exactly the designed samples carrying a premature stop, marker substitution missense).

**Fully reproducible from seed 20260926** — running the pipeline regenerates every data file, result and figure byte-for-byte.

## Pipeline (one command)

```bash
bash scripts/run_all.sh          # logs everything to results/run_log.txt
```

| Script | Purpose |
|---|---|
| `01_simulate_dataset.py` | Builds the reference, 12 samples and the mini database (self-verifying) |
| `02_qc_and_orfs.py` | Length, GC, six-frame ORF scan, reference translation |
| `03_variant_calling.py` | Global Needleman–Wunsch alignment; exact position-mapped variant calling; functional annotation; protein consequences |
| `04_msa_conservation.py` | FAMSA multiple alignment; conservation profile; cross-homolog enrichment test |
| `05_local_blast.py` | BLAST-style seed-and-extend search (word 11, +2/−3, λ 0.625, K 0.41) |
| `06_mutation_patterns_markers.py` | Substitution spectrum; hotspots; Fisher exact association; marker panel performance |
| `07_make_figures.py` | All report figures, drawn from the result files |

**Tools:** Python 3.12, Biopython 1.88 (PairwiseAligner), FAMSA via pyfamsa 0.7.0, SciPy 1.18 (Fisher exact), Matplotlib, python-docx.

## Method notes (the interesting engineering)

- **Exact variant calling.** Naive alignment-based SNV calling placed substitutions at ambiguous ±1 positions (global alignments of equal-length sequences have many equally optimal solutions), creating phantom sites. The caller now builds a reference→sample position map and compares bases directly, which is exact for equal-length sequences.
- **Left-normalised indels** (VCF convention) so indel labels are deterministic.
- **Frame-aware annotation.** Variants downstream of a frameshift are flagged *uninterpreted* rather than mis-annotated, and protein consequences are computed by translating each sample's own reading frame.
- **Simulation realism.** Background variants are transition-weighted so the spectrum (Ts/Tv = 2.36) resembles real mutational processes.

## Honest limitations

The data are simulated, so no result here is a biological claim. The cohort (6 + 6) is far too small to estimate marker performance, and the association p-values are discovery-cohort values without an independent validation cohort. The homology search ran against a simulated four-sequence database, and no base-quality scores were simulated.
